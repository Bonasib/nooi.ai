# سياسة الاستخدام المقبول

_nooi.ai · آخر تحديث: 2026-09-26_

## عدم تسامح مطلقاً

يُمنع منعاً باتاً أي محتوى جنسي أو ذي طابع جنسي يتعلق بالقاصرين، ونحجبه ونغلق الحساب ونبلغ الجهات المختصة.

## المحظورات

المحتوى الإباحي أو الجنسي الصريح، والصور الحميمة لأي شخص دون موافقته، والتزييف العميق لأشخاص حقيقيين دون موافقتهم أو بقصد الخداع، وانتحال الشخصية، والتحرش والكراهية والتهديد، والمحتوى الذي يروّج للعنف أو الإرهاب، والسلع والأنشطة غير النظامية، والاحتيال والإعلانات المضللة، والتضليل الانتخابي، والبرمجيات الضارة والرسائل المزعجة.

## الأشخاص الحقيقيون

لا تُنشئ محتوى يُظهر وجه أو صوت شخص حقيقي إلا بموافقته، وضع علامة المحتوى المولّد بالذكاء الاصطناعي حيث يوجب النظام أو المنصة ذلك.

## الملكية الفكرية

لا تستخدم شخصيات أو موسيقى أو شعارات أو مقاطع لا تملك حقوقها.

## إساءة استخدام المنصة

لا تتجاوز فلاتر الأمان أو حدود الرصيد أو الحماية، ولا تُعد بيع الوصول دون إذن.

## التطبيق

نستخدم فلاتر آلية ومراجعة بشرية، وقد تؤدي المخالفة إلى حذف المحتوى أو فقدان الرصيد أو إيقاف الحساب أو إغلاقه نهائياً.
